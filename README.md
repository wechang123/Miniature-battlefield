# 야자게임 (Night Study Escape)

## 게임 소개
야간자율학습 시간, 교실을 탈출하라!

선생님과 감시 드론을 피해 교실에서 탈출하는 3D 액션 게임입니다.
연필창, 지우개 폭탄, 고무줄 새총 등 학용품을 무기로 활용하여 적을 처치하고 탈출하세요.

## 조작법
- **WASD**: 이동
- **Space**: 점프
- **마우스**: 시점 조작
- **좌클릭**: 공격/던지기
- **E**: 아이템 줍기
- **ESC**: 일시정지

## 게임 특징
- 라운드 기반 진행
- 다양한 학용품 무기 시스템
- 선생님 AI와 드론 AI
- HP 시스템

## 개발 환경
- Unity 6
- C#

## 팀원
- 컴퓨터그래픽스 팀 프로젝트
